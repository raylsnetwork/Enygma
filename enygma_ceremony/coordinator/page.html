Enygma setup ceremony

Enygma's privacy rests on a set of cryptographic keys. This ceremony makes them together, so that no one ever holds the secret that could forge a proof. You contribute from your own computer, with a program you get from GitHub, not from this server.

1Phase 1: the shared foundation

One ceremony that every Enygma protocol builds on.

2Phase 2: keys for each protocol

One ceremony per protocol, built on Phase 1.

Each contribution mixes fresh randomness from a participant's computer into the keys, and that randomness is then thrown away. The keys are secure as long as one participant in each phase was honest and ran a program this server did not give them. That can be you.

This server never sends you code. The program that draws your randomness comes from the ceremony's GitHub release, built in the open from a tagged commit, or from source you build yourself.

  1. Open the ceremony's release on GitHub. Take the link from the ceremony's announcement or the repository, rather than from this page alone.
  2. Paste the command for your system from the release notes into a terminal (PowerShell on Windows). It checks the program's sha256 against the release, then runs it. It waits for your turn by itself; leave it running until it says you are done, then publish the receipt it prints.
