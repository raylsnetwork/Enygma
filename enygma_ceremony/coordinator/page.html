Enygma setup ceremony

Enygma's privacy rests on a set of cryptographic keys. This ceremony makes them together, so that no one ever holds the secret that could forge a proof. Contributing takes one click and a few minutes of your computer's time.

1Phase 1: the shared foundation

One ceremony that every Enygma protocol builds on.

2Phase 2: keys for each protocol

One ceremony per protocol, built on Phase 1.

Each contribution mixes fresh randomness from a participant's computer into the keys, and that randomness is then thrown away. The keys are secure as long as one participant in each phase was honest, and that can be you.
