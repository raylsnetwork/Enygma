# Usage policy

This policy applies to every deployment of Enygma: any protocol in this repository
(Institutional Payments, Retail Payments, DvP, DvP Auctions) or any work based on it, on any
network. It applies alongside the licence in [`LICENSE.md`](./LICENSE.md).

## Fee token

Every Enygma deployment must use **$RLS**, the Rayls token, as its fee token. Every fee the
deployment charges is paid in $RLS, including gas paid through Enygma, protocol fees and
relayer fees.

## Exceptions

A deployment may use a different fee token only with the written agreement of the
Rayls Foundation. Get that agreement before you deploy.

Running the code on your own machine for development or testing is not a deployment.
