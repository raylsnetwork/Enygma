Random Factor · TxRandomValues
Each transfer produces 6 blinding factors. The sender's txRandom[0] = Σ raw_r[1..5]; each receiver's txRandom[i] = P − raw_r[i], so Σ txRandom ≡ 0 (mod P). Each value below is the actual txRandomValue used in Com(v, r) = v·G + r·H — use these directly to verify on-chain balances.
Run a transfer first, then click Load Last Transfer.
Cumulative R · Balance Verification
Running sum of txRandom across all transfers. Pedersen commitments are additive: Σ Com(v, r) = Com(Σv, Σr) — so Com(cumulative_balance, cumulative_r) must equal the on-chain commitment point. Use these r values together with the Pedersen Calculator above to cross-check.
